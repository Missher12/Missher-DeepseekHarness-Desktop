# 插件维护入口

本目录维护独立插件导航，各插件的业务源码在对应独立仓库维护。当前入口、访问要求和安装说明见[插件目录](README.zh.md)；原插件导入历史及早期发布清单保留原有身份，不把旧包版本标为当前版本。

当前记忆系统使用 `Missher12/Missher-DSH-Memory-Native`，Media 使用 `Missher12/Media-Missher-Ego`。MSE Learning、Media-Missher-Ego、Memory TDAI 和 Windows Guard 保持私有；维护中、可选、旧版及暂停项目按插件目录区分，不重新启用旧插件。

保留各插件自己的构建、配置、安装、卸载和历史，不引入共同兼容包。禁止提交凭据、真实聊天、附件、记忆库、学习记录、采集数据、生产 profile 或安装备份。源码发布不等于已更新日常应用。
